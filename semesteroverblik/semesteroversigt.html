02

WordPress

Et kort forløb om CMS, domæner og hosting, indholdsstruktur samt tilpasning med HTML, CSS og JavaScript. Forløbet danner grundlag for at bruge WordPress som headless CMS i Dynamic User Interface.

03

Dynamic User Interface

Et gruppeprojekt, hvor design og programmering udvikles i tæt samspil – fra Figma, designsystemer og komponenter til en kompleks dynamisk brugergrænseflade i Next.js og React. Headless WordPress, API'er og andre datakilder indgår i arkitekturen sammen med UI-værktøjer som Tailwind CSS og shadcn/ui. Figma MCP og AI-tools bruges til idéudvikling, implementering, sparring, review og kvalitetssikring.

Eksamen: Mundtlig gruppeprøve med præsentation og eksamination om produkt, proces og faglige refleksioner.
