# RACE - Product optimization: Case 1 · Kick-off og codebase audit - 25-08-2026

## Formål

At starte Case 1 med en systematisk analyse af en eksisterende React-løsning og omsætte observationer til en prioriteret optimeringsplan.

Efter undervisningen skal du have dokumenteret løsningens nuværende tilstand, valgt de vigtigste forbedringer og etableret et individuelt Git-workflow med issues, feature branches og pull requests.

## Forberedelse

- Sørg for, at Git og Node.js fungerer på din computer. Det forventes, at du kan clone, committe, pushe og arbejde i en branch.
- Genbesøg tjeklisten og principperne fra 19. og 21. august.

## Agenda

1. Introduktion til Case 1, krav, rammer og forventet dokumentation
2. Kør løsningen lokalt og kortlæg dens funktionalitet
3. Codebase audit
   - accessibility og semantisk HTML
   - stylingens placering, ansvar og genbrug
   - navngivning, struktur, arkitektur og komponentopdeling
   - fejlhåndtering og robuste UI-states
   - Supabase, datamodel og relationer
   - konfiguration, Git-historik og deployment
4. Individuelt workflow: issue → feature branch → pull request → peer review → merge
5. Etablér en baseline med skærmbilleder, kendte problemer og relevante målinger
6. Prioritér forbedringer efter effekt, risiko og arbejdsomfang
7. Opret issues med tydelige acceptkriterier, og planlæg din første feature branch
