# RACE - Product optimization: JavaScript for React - 21-08-2026

## Formål

Lad os tage et skridt tilbage og træne de vigtigste JavaScript-koncepter, du skal kunne for at skrive effektiv React-kode.

React er faktisk ikke så svært – det handler primært om komponenter og state – men JavaScript-delen kan være svær.

Derfor træner vi koncepterne i almindelig JavaScript og anvender dem derefter i en React-kontekst.

## Agenda

Vi går fra egne kodeeksempler til fælles JavaScript-koncepter, træner dem i praksis og kobler dem til React.

<details style="margin-left: 1.5rem;">
<summary><strong>1. Dagens scope: JavaScript for React</strong></summary>
<ul>
<li>Hvorfor er et sikkert JavaScript-fundament vigtigt, når du arbejder med React?</li>
<li>Vi træner JavaScript-koncepterne først og kobler dem derefter til React.</li>
</ul>
</details>

<details style="margin-left: 1.5rem;">
<summary><strong>2. Eksempler fra 2. semester</strong></summary>
<ul>
<li>Tal kort med en medstuderende om den kode, du har fundet.</li>
<li>Del ét eksempel i vores fælles Padlet: et kodeudsnit eller link, hvad du tror koden gør, og hvad du er i tvivl om.</li>
<li>Vi bruger eksemplerne til at finde fælles mønstre og prioritere dagens koncepter.</li>
</ul>
</details>

<details style="margin-left: 1.5rem;">
<summary><strong>3. JavaScript-koncepter</strong></summary>
<p>Vi skaber overblik over de JavaScript-koncepter, der er særligt vigtige, når du arbejder med React.</p>
<p><strong>Dagens fokus</strong></p>
<ul>
<li>functions, arrow functions, callback functions og default parameters</li>
<li>objekter og arrays: property access, shorthand properties, destructuring samt rest og spread</li>
<li>immutable opdatering af objekter og arrays</li>
<li>array-metoderne <code>map</code>, <code>filter</code> og <code>find</code></li>
<li>template literals</li>
<li>ternary operator, logiske operatorer (<code>&amp;&amp;</code> og <code>||</code>) og conditional rendering</li>
<li>optional chaining (<code>?.</code>) og nullish coalescing (<code>??</code>)</li>
<li>promises og sammenhængen mellem promises og <code>async</code>/<code>await</code></li>
<li><code>import</code> og <code>export</code> med ES modules</li>
</ul>
<p><strong>Det forventes, at du kender eller kan genkende</strong></p>
<ul>
<li><code>const</code>, <code>let</code>, datatyper, scope, truthy/falsy og sammenligninger</li>
<li>parametre og return values</li>
<li>closures</li>
<li>array-metoderne <code>forEach</code>, <code>some</code>, <code>every</code>, <code>includes</code> og <code>reduce</code></li>
</ul>
</details>

<details style="margin-left: 1.5rem;">
<summary><strong>4. Fra JavaScript til optimeret React</strong></summary>
<ul>
<li>Løs små øvelser med udvalgte koncepter i almindelig JavaScript.</li>
<li>Overfør derefter de samme koncepter til React: komponenter, props, event handlers, state-opdateringer, conditional rendering og rendering af lister.</li>
</ul>
</details>

<details style="margin-left: 1.5rem;">
<summary><strong>5. Brug koncepterne i din egen kode</strong></summary>
<ul>
<li>Find et JavaScript-flow i din egen Web App, og identificér dagens koncepter i koden.</li>
<li>Forklar flowet, og omskriv koden, hvis den kan gøres tydeligere.</li>
</ul>
</details>

<details style="margin-left: 1.5rem;">
<summary><strong>6. Opsamling: Tilbage til Padlet</strong></summary>
<ul>
<li>Genbesøg det eksempel, du delte i Padlet. Kan du nu forklare, hvad koden gør, og hvilke JavaScript-koncepter den bruger?</li>
<li>Tilføj din forklaring eller et spørgsmål, du stadig mangler svar på.</li>
<li>Hvilke JavaScript-koncepter skal du træne videre?</li>
</ul>
</details>
