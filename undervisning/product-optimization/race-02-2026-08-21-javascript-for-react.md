# RACE - Product optimization: JavaScript for React - 21-08-2026

## Formål

Lad os tage et skridt tilbage og træne de vigtigste JavaScript-koncepter, du skal kunne for at skrive effektiv React-kode. React er faktisk ikke så svært – det handler primært om komponenter og state – men JavaScript-delen kan være svær. Derfor træner vi koncepterne i almindelig JavaScript og anvender dem derefter i en React-kontekst.

<hr style="margin: 2rem 0;">

## Forberedelse

- Genbesøg din Web App fra 2. semester, og find et eksempel på JavaScript, du har svært ved at forklare.
- Har du brug for et recap, kan du bruge [JavaScript.info](https://javascript.info/) eller de relevante dele af [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide).

<hr style="margin: 2rem 0;">

## Agenda

1. Diagnostisk kodeøvelse: Forudsig og forklar JavaScript uden hjælpemidler.
2. Målrettet opsamling på de koncepter, øvelsen viser behov for:
   - værdier, datatyper, truthy/falsy og sammenligninger
   - `const`, `let`, scope og immutability
   - objekter, arrays, destructuring og spread
   - funktioner, callbacks og event handlers
   - `map`, `filter` og `find`
   - moduler, `import` og `export`
   - promises og `async`/`await`
3. Små JavaScript-øvelser med data, funktioner og array-metoder.
4. Find de samme koncepter i React-komponenter, props, event handlers og rendering af lister.
5. Forklar et JavaScript-flow fra din egen Web App, og omskriv det, hvis det kan gøres tydeligere.
6. Opsamling: Hvilke JavaScript-koncepter skal du træne videre?
