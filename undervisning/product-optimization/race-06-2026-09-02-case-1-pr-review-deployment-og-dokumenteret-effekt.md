# RACE - Product optimization: Case 1 · PR-review, deployment og dokumenteret effekt - 02-09-2026

## Formål

At kvalitetssikre den optimerede React-løsning og dokumentere, om ændringerne reelt har forbedret produktet og kodebasen.

Efter undervisningen skal du have en stabil deployment via GitHub Actions, et gennemført peer review og en kort, fagligt begrundet før/efter-dokumentation.

## Forberedelse

- Push de ændringer, der er klar til review, til dine feature branches.
- Opdatér din liste over kendte problemer og gennemførte forbedringer.

## Agenda

1. Status og afgrænsning: Hvad skal være færdigt i dag?
2. Opstil kvalitetskriterier ud fra kompetencer fra 2. semester og casens optimeringsmål
3. Anvend kendte teknikker i et samlet kvalitetstjek
   - fejl i konsollen og netværkskald
   - responsive layouts og grundlæggende tilgængelighed
   - metadata, identitet og favicon
   - loading, fejlbeskeder og edge cases
4. Enkel vurdering af performance og unødvendige renders eller requests
5. Opret eller færdiggør en pull request fra feature branch til `main`
6. Gennemfør peer code review på en medstuderendes pull request
7. Bearbejd feedback, flet ændringerne, og verificér deployment via GitHub Actions
8. Kontrollér environment variables og den publicerede løsning
9. Før/efter-dokumentation med begrundelse og evidens
10. Kort præsentation og retrospektiv: Hvad gav størst effekt?
