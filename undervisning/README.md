# Undervisning

Undervisningsmaterialerne er organiseret efter forløb. Hvert forløb kan efter behov opdeles i:

- `undervisningsgange/` – noter og planer for de enkelte undervisningsdage
- `slides/` – præsentationer og eksporterede PDF-filer
- `opgaver/` – briefs, øvelser og afleveringer
- `materialer/` – kodeeksempler, links og øvrige ressourcer
