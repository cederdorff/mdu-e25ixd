# RACE - Dynamic User Interface: Faciliteret vejledning - 23-11-2026

## Formål

I dag er der faciliteret vejledning, og det er frivilligt at møde op. Jeg sidder i 3.17A/3.17B fra kl. 8.15, så kom forbi, hvis I har brug for hjælp.

I afleverer i morgen, tirsdag kl. 12.00 i WISEflow. Så brug dagen på at blive færdige, og spørg hellere én gang for meget.

<hr style="margin: 2rem 0;">

## Forberedelse

Tag jeres spørgsmål med, og hav jeres live-site, repo og Figma-fil åbne, så vi hurtigt kan kigge på det sammen.

<hr style="margin: 2rem 0;">

## Agenda

Vejledning og projektarbejde hele dagen. Jeg kommer rundt til grupperne, men I kan også bare fange mig.
