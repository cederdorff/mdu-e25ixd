Hvad så I? · er CSR et problem?

CSR har en pris

Prisen ved CSR
  • Tom side først. Brugeren venter på JavaScript og data — især på mobil og langsomt net. Det så I i Lighthouse.
  • Søgemaskiner og link previews. Google kan køre JavaScript, men med forsinkelse. Mange bots — fx link previews i Slack og LinkedIn — ser kun <div id="root">.
  • Et vandfald af requests. HTML → JavaScript → fetch → render. Hvert trin venter på det forrige.
  • Alt ligger i browseren. API-kald og nøgler kan ses af alle.
CSR fungerer fint, når …
  • Appen er bag login — fx et dashboard eller et admin-panel.
  • Indholdet er personligt og ikke skal findes på Google.
  • Brugeren bliver længe og interagerer meget — fx et værktøj som Figma.

Jeres Post App fra Product optimization var fin som CSR.

I dag viser vi offentligt indhold fra WordPress, som skal vises hurtigt og kunne findes. Derfor renderer vi på serveren — og det er præcis det, Next.js er bygget til.

Client spørger — server svarer

En computer på nettet

GitHub Pages, Simply.com, Vercel — eller localhost
Client
Programmet, der beder om noget og viser det for brugeren.
Server
Programmet, der venter på requests og sender svar tilbage.
Request
En forespørgsel over HTTP: en URL, en metode som GET og evt. data.
Response
Svaret: en statuskode som 200 eller 404 og et indhold.

Hvad er Next.js?

Next.js er et React-framework

Library

React

Bygger UI'et af komponenter, props og state.

Du bestemmer selv, hvordan resten af appen hænger sammen.
Build tool

Vite

Starter en dev-server og bundler din kode til filer, browseren kan køre.

Det, I har brugt indtil nu — sammen med React Router.
Framework

Next.js

React + routing, server, datahentning og build i én samlet løsning.

Frameworket bestemmer strukturen. Du udfylder den med dine komponenter.
Library
Kode, du kalder, når du har brug for den.
Framework
En ramme, der kalder din kode — fx når Next.js finder din page.js.

export default async function PostsPage() {
  const response = await fetch(
    `${process.env.WORDPRESS_URL}/wp-json/wp/v2/posts`
  );
  const posts = await response.json();

  return (
    <main>
      <h1>Posts</h1>
      <ul>
        {posts.map((post) => (
          <li key={post.id}>{post.title.rendered}</li>
        ))}
      </ul>
    </main>
  );
}

Navnet er en advarsel

I orden
  • Din egen WordPress, hvor kun betroede redaktører kan skrive indhold
  • Du kender og kontrollerer kilden — og ved, hvem der har adgang
