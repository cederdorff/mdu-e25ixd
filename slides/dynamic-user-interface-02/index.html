1.2 · Variants bliver til props og CSS

Pillen er en <button>

components/Pill.js 
import styles from "./Pill.module.css";

export default function Pill({ type = "primary", onClick, children }) {
  return (
    <button
      type="button"
      className={`${styles.pill} ${styles[type]}`}
      onClick={onClick}
    >
      {children}
    </button>
  );
}

// Brug:
<Pill type="secondary">Secondary</Pill>

Type → propEt valg, når pillen bruges. type="primary" vælger klassen .primary.

State → CSSHover sker af sig selv. Den bliver til :hover og :focus-visible — ikke en prop.

Teksten → childrenSom tekst i en almindelig <button>.

type="button"HTML-attributten: knappen sender ikke en formular. Den er ikke din prop.

1.3 · Prototypen bliver til state

PillModal forbinder pill og modal

components/PillModal.js 
"use client";

import { useState } from "react";
import Modal from "./Modal";
import Pill from "./Pill";

export default function PillModal({ type, label, title, text }) {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Pill type={type} onClick={() => setIsOpen(true)}>{label}</Pill>
      <Modal isOpen={isOpen} onClose={() => setIsOpen(false)}
        title={title} text={text} />
    </>
  );
}

On click → setIsOpen(true)Prototypens klik bliver til en event handler.

Close overlay → onCloseModalen fortæller, at den er lukket, og state følger med.

"use client"Komponenten bruger state og events. Pill behøver det ikke — den får bare onClick.

Siden bliver simpel<PillModal type="primary" label="Hick's Law" … /> i page.js.

1.3 · <dialog> med en ref

Modal.js kalder showModal()

components/Modal.js · uddrag 
const dialogRef = useRef(null);

useEffect(() => {
  if (isOpen) {
    dialogRef.current.showModal();
  } else {
    dialogRef.current.close();
  }
}, [isOpen]);

function handleClick(event) {
  if (event.target === event.currentTarget) {
    onClose();
  }
}

<dialog ref={dialogRef} onClose={onClose} onClick={handleClick}>
  <div className={styles.content}>…</div>
</dialog>

refGiver adgang til selve <dialog>-elementet.

useEffectNår isOpen skifter, åbner eller lukker modalen.

onCloseKører også ved Esc, så state er i sync.

Klik udenforRammer <dialog> selv. Klik på indholdet rammer .content.

1.5 · Smart Animate bliver til transition

Modalen animerer ind og ud

components/Modal.module.css · nederst 
.modal {
  opacity: 0;
  scale: 0.95;
  transition:
    opacity 300ms ease-out,
    scale 300ms ease-out,
    overlay 300ms ease-out allow-discrete,
    display 300ms ease-out allow-discrete;
}

.modal[open] {
  opacity: 1;
  scale: 1;
}

@starting-style {
  .modal[open] {
    opacity: 0;
    scale: 0.95;
  }
}

Varighed og easingFind dem i din prototype, fx Ease out, 300ms.

@starting-styleHvor animationen starter, når modalen åbner.

Rul 2a · prompten

Fortæl agenten det, den ikke kan se

Byg komponenterne Pill og Modal fra mit Figma-design: <indsæt dit link>

Brug Figma MCP-serveren til at læse designet, dets variables og component properties.

Projektet er Next.js med App Router og JavaScript. Følg disse regler:
- Skriv JavaScript, ikke TypeScript.
- Læg de nye filer i components/agent/, og vis komponenterne på en ny side i app/agent/page.js. Rør ikke de andre filer i components/.
- Brug CSS Modules og de tokens, der allerede ligger i app/globals.css. Ingen Tailwind, inline styles eller hardcodede værdier, hvor der findes et token.
- Pillen er en <button type="button">. Prop'en type vælger Primary eller Secondary. Hover og fokus laves med :hover og :focus-visible i CSS.
- Modalen er en <dialog>, der åbnes med showModal(), så fokus og Esc virker. Klik udenfor lukker den. Prop'en showSeparator viser eller skjuler separatoren.
- Et klik på pillen åbner modalen. Brug kun "use client" i de komponenter, der har brug for state eller effects.
- Smart Animate bliver til en CSS transition.

Forklar kort bagefter, hvilke filer du har lavet, og hvilke tokens du har brugt.

Linket: Højreklik på din frame i Figma → Copy link to selection. Prompten står også i opgavefilen, så du kan kopiere den.

Ekstra 3a · overlay fra pillen

Mål pillen, når den bliver klikket

components/PillModal.js og Modal.js · uddrag 
// PillModal.js
const [origin, setOrigin] = useState({ x: 0, y: 0 });

function handleOpen(event) {
  const pill = event.currentTarget.getBoundingClientRect();
  setOrigin({
    x: pill.left + pill.width / 2 - window.innerWidth / 2,
    y: pill.top + pill.height / 2 - window.innerHeight / 2
  });
  setIsOpen(true);
}

// Modal.js
const originStyle = {
  "--origin-x": `${origin.x}px`,
  "--origin-y": `${origin.y}px`
};

<dialog … style={originStyle}>

Ikke en ny variantProps og states er de samme. Det er bevægelsen mellem lukket og åben, der ændrer sig.

getBoundingClientRect()Giver pillens position. Modalen åbner midt på skærmen, så vi gemmer afstanden derfra.

origin → ModalSend den som prop fra PillModal, og brug handleOpen som onClick.

style med custom propertiesVærdien kendes først ved klikket. Derfor er style okay her.

Ekstra 3a · start dér, hvor pillen er

Lukket ligger modalen på pillen

components/Modal.module.css · ændret fra 1.5 
.modal {
  scale: 0.2;
  translate: var(--origin-x) var(--origin-y);
  transition:
    opacity 300ms ease-out,
    scale 300ms ease-out,
    translate 300ms ease-out,
    overlay 300ms ease-out allow-discrete,
    display 300ms ease-out allow-discrete;
}

.modal[open] {
  translate: 0 0;
}

@starting-style {
  .modal[open] {
    scale: 0.2;
    translate: var(--origin-x) var(--origin-y);
  }
}

Lukket: på pillentranslate flytter modalen hen over pillen, og scale: 0.2 gør den lille.

Åben: i midtentranslate: 0 0. Transition klarer vejen derimellem, begge veje.

@starting-styleSamme startpunkt, når modalen åbner.

Mindre bevægelseUnder prefers-reduced-motion bliver scale og translate til none. Så fader modalen kun.

Ekstra 3b · på stedet

Pillen folder sig ud, hvor den er

components/PillDisclosure.js · uddrag 
const [isOpen, setIsOpen] = useState(false);
const id = useId();

function handleClick() {
  if (!document.startViewTransition) {
    setIsOpen(!isOpen);
    return;
  }
  document.startViewTransition(() => {
    flushSync(() => setIsOpen(!isOpen));
  });
}

<div className={…} style={{ viewTransitionName: `item${id}` }}>
  <Pill onClick={handleClick} aria-expanded={isOpen}
    style={{ viewTransitionName: `pill${id}` }}>{label}</Pill>
  {isOpen && <div className={styles.content}>…</div>}
</div>

Ikke en modalSiden bag kan stadig bruges. Derfor en <button aria-expanded> og ingen <dialog>.

startViewTransition()Browseren tager et billede før og efter og animerer imellem — også de pills, der flytter sig.

flushSyncReact opdaterer siden med det samme, så billedet efter er rigtigt.

useId()Giver hvert element et unikt view-transition-name.

Ekstra 3b · Smart Animate med view transitions

Browseren animerer resten

app/globals.css · nederst 
/* Smart Animate, ease out, 300ms */
::view-transition-group(*) {
  animation-duration: 300ms;
  animation-timing-function: ease-out;
}

@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*),
  ::view-transition-old(*),
  ::view-transition-new(*) {
    animation: none;
  }
}

Variant Open → .openKant, radius, padding og bredde i PillDisclosure.module.css. Samme kantfarve som pillen, så den ser ud til at vokse.

Smart AnimateVarighed og easing fra din prototype på hver gruppe. Resten klarer browseren.

I globals.cssEn CSS Module kræver en klasse i selektoren, og det har den her ikke.
