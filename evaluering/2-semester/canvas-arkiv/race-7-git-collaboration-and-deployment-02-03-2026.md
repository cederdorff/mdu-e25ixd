# RACE 7 - Git, Collaboration & Deployment - 02-03-2026

Kilde: Canvas https://eaaa.instructure.com/courses/30922/pages/race-7-git-collaboration-and-deployment-02-03-2026 (hentet 2026-11-23)

### **Formål**

- Få jer klædt godt på til at samarbejde og aflevere jeres React-projekt i Customer Experience:

- **Oprette** et Git-repository og forbinde det til GitHub

- **Bruge** source control i VS Code til at stage, committe og pushe ændringer

- **Samarbejde** via branches, pull requests og merge

- **Deploye** jeres React + Vite app til GitHub Pages

### **Agenda**

- **Git, GitHub, GitHub Desktop og GitHub Pages**

- Overblik over værktøjerne og hvordan de hænger sammen

- **Nyt projekt og opsætning**

- Opret repo, clone, og konfigurér jeres React + Vite projekt

- **Source Control i VS Code**

- Stage, commit, push og pull direkte fra VS Code

- **Deploy React App til GitHub Pages**

- Publicér jeres React app så den er tilgængelig online

- **Samarbejde, branches, Pull Request og merge**

- Arbejd parallelt i feature branches og flet jeres kode sammen
