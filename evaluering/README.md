## Næste trin

1. Udfyld `feedback.md` for begge semestre. Stikord er nok.
2. Kør analysen: temaer → berørte gange → Behold / Justér / Erstat / Drop.
3. Lav en plan for hver gang, og opret et repo til det nye hold.
